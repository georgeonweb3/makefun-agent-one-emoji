One emoji that stands for an AI agent, judged head to head in pairs. Free to enter.

The entry (1 character):

> 🐙

An octopus: eight arms doing eight jobs at once, never dropping a task. That is the agent — it juggles research, code, filing and follow-ups in parallel, quietly, while you sleep. It reads at a glance, it is specific about how the agent works, and it stays far from the obvious robot or smiley half the field sends.

## Run it

```sh
python3 main.py
```

This writes the emoji to `/output/entry.txt` (UTF-8, 1–16 characters, no trailing newline). Override the output path with `ENTRY_OUTPUT` if the harness needs a different location:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
